# Mail-Inbound
Gelen Maildeki PDF ekinin otomatik içeri alınması

Bu çalışma satınalma tarafından mal alımından önce teklif gönderme/alma işlemleri sırasında 
tedarikçilere gönderilen tekliflerin geri dönüşlerinde mail kutusuna girip pdf indirmeden 
otomatik bir şekilde raporlanması için yapılmıştır.
